# Checklist uji: Panel Admin Kelas dan Menu

- [ ] Admin Kelas: rail berisi Panel Admin. Murid tidak punya Panel Admin dan Kabar Sistem.
- [ ] Panel menampilkan ringkasan (anggota aktif, menunggu persetujuan, jumlah role) dan enam tab: Ringkasan, Anggota, Peran, Persetujuan, Kode kelas, Log.
- [ ] Tiap tab membuka halamannya dengan deretan tab tetap tampil dan tab aktif bertanda.
- [ ] Pemegang `akun.approve` tanpa Admin Kelas: tidak punya Panel, Persetujuan tetap ada di rail.
- [ ] Murid membuka `#/panel`, `#/peran`, `#/log`: ditolak dengan pesan.
- [ ] Ponsel: bilah bawah berisi Mading, Jadwal, Tugas, Menu, Profil. "Menu" berlabel.
- [ ] Halaman Menu menampilkan hanya fitur yang boleh dibuka akun itu.
- [ ] Murid baru: fitur baru (piket, voting, kas, organigram) mati sampai Admin Kelas menyalakan di matriks izin.
- [ ] Bilah bawah tidak menutup item terakhir halaman (gulir sampai bawah).
- [ ] Fokus keyboard terlihat di semua tab dan tautan.
